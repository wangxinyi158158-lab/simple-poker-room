# 扑克好友房（免登录在线版）

手机、电脑浏览器都能打开；不同 Wi-Fi/不同城市也能玩。功能：创建/加入房间、至少 2 人、所有人准备后每人随机发 5 张牌、所有人可见、初始 0 分、积分可转让且允许负数。

## 最简单的上线方法（只需做一次）

**注意：这个压缩包是已经准备好的网页项目，不是已经发布的公网网址。** 要让不同网络的朋友访问，必须把项目放到一个在线托管平台。当前聊天环境不能替你创建第三方账号或替你确认部署成功。

1. 下载并解压这个 ZIP。
2. 把整个 `simple-poker-room` 文件夹上传到你自己的 GitHub 仓库（仓库可设为 Private）。
3. 登录 Render，选择 **New + → Web Service**，连接刚才的 GitHub 仓库。
4. Render 会读取 `render.yaml`；如果让你填写，使用：
   - Runtime：Node
   - Build Command：`npm install`
   - Start Command：`npm start`
5. 点击 Deploy。部署成功后 Render 会给你一个 `https://...onrender.com` 网址。
6. 把这个网址发给朋友。你们各自打开网址，创建者把房间号发给其他玩家即可。

## 重要说明

- 免费托管平台的可用性和休眠规则可能变化；休眠后第一次打开可能需要等待启动。
- 房间和积分暂存在服务器内存中；服务器重启或重新部署后，当前房间会清空。
- 无需登录，但房间号相当于入场凭证，请只分享给要一起玩的朋友。
- 需要 Node.js 18+ 才能在自己的电脑本地运行；本地访问地址是 `http://localhost:3000`。
